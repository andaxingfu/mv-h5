# 稳稳接住你 · H5 MV（三个版本）

三个版本都是单文件 H5，不依赖构建，也不需要 CDN，共用同一首 song.mp3。竖屏 9:16，在桌面浏览器上最大宽度 430px。

| 文件 | 版本 | 风格 |
|---|---|---|
| index.html（= v3-chat.html） | v3「对方正在输入…」 | 原创概念：凌晨 2 点和 AI 的一段聊天。暖色暗黑主题，奶油色 AI 气泡和珊瑚色用户气泡，有一个会掉下来的小人「你」 |
| v2-terminal.html | v2「稳稳接住你.exe」 | 程序员 / 终端风格：代码、颜文字、动态排版、太空侵略者小游戏 |
| v1-aurora.html | v1「光影」 | 霓虹极光，粒子和频谱环随音乐律动 |

## 运行
解压后在当前目录启动本地服务器（不要直接双击 file:// 打开）：

    python3 -m http.server 8765

然后访问：
- http://127.0.0.1:8765/ （v3）
- http://127.0.0.1:8765/v2-terminal.html
- http://127.0.0.1:8765/v1-aurora.html

## 操作（v2 / v3）
- 封面轻触开始（v3 也可以上滑）
- 点画面暂停 / 继续，底部有暂停按钮和进度条，进度条可以拖动
- 画面完全由 audio.currentTime 驱动，跳到任意位置都对得上
- 播完后出现结束卡，可以重播（v3 的按钮是「重新打开」）
- 调试：在地址后加 `?t=秒`，画面会停在那一刻

## 节拍
BPM ≈ 148.3，第一拍在 0.242s 左右。场景切换、气泡弹出和副歌的闪屏 / 抖屏都对齐这套节拍。

## v3 小彩蛋
状态栏时间从 02:00 走到 02:43（歌曲每 1 秒 = 1 分钟），电量随歌曲下降。
